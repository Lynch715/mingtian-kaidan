# 明天一定开单

在南桥营业部做满30天的保险销售模拟器。

[开始游戏](https://lynch715.github.io/mingtian-kaidan/)

每天六格时间：找客户、了解需求、面谈、选择方案、成交与回访，也要安排生活支出和亲友关系。包含两种开局、30段每日主线、15段日常事件、4位客户专属事件、1条带补件分支的理赔故事、3条跨天后果和6种结局。

本轮重排现有客户的接洽与考虑时间，把成交和回访铺到月底；降低前期集中的专业成长。普通操作直接显示记录，首单、达标和理赔结案保留醒目结果。确认方案前显示实际缺项及考虑日期，首次回访完成后明确收尾。收工前回复补充故事及日常插曲，不必为了看剧情额外消耗行动；联系人已满时不再许诺无法新增的咨询。

保留v1自动及手动存档。新开局采用新的月份安排；旧档不降低属性、不改已认识客户的考虑日期、不重算历史收入，也不重播完成的剧情。换设备前可在生活账导出JSON，到新设备导入。

手机正文独立滚动，底部操作保持可达；保留双指缩放限制、网页和手机桌面图标。

## 验证

Node.js 20及以上运行 `node --test qa/*.test.mjs`。68项测试涵盖新节奏、两种身份的20条正常月份路线、旧档恢复与续玩、历史规则对照、收工剧情队列和移动输入。qa/legacy-engine.mjs仅为历史规则回归入口，新开局测试直接使用正式引擎。

人物、公司及产品规则均为虚构。游戏静态运行，不依赖实时大模型。
