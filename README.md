# 明天一定开单

在南桥营业部做满30天的保险销售模拟器。

[开始游戏](https://lynch715.github.io/mingtian-kaidan/)

每天六格时间：找客户、了解需求、面谈、选择方案、成交与回访，也要安排生活支出和亲友关系。包含两种开局、30段每日主线、15段日常事件、4位客户专属事件、1条跨天理赔故事、3条选择后果和6种结局。

本月更新打磨30天文案，拆开相似剧情，行动结果显示实际进展，夜间回顾按当天行动生成。手机剧情、客户和方案正文独立滚动，底部操作可达；补齐短横屏布局、双指缩放限制、网页及手机桌面图标。

进度自动保存在当前浏览器，沿用原v1存档。换设备前在生活账导出JSON，再到新设备导入。旧日记、旧结果和旧结局保留，已经完成的故事不重播。

人物、公司及产品规则均为虚构。游戏静态运行，不依赖实时大模型。
