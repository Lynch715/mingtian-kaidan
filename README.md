# 明天一定开单

在南桥营业部做满30天的保险销售模拟器。

[开始游戏](https://lynch715.github.io/mingtian-kaidan/)

每天六格时间：找客户、了解需求、面谈、选择方案、成交与回访，也要安排生活支出和亲友关系。包含两种开局、30段每日主线、15段日常事件、4位客户专属事件、1条带补件分支的理赔故事、3条跨天后果和6种结局。

本轮完善新手提示：推荐联系人可直接打开资料；跟进和面谈预告实际资料、信任和专业收益；等待时说明下一次联系与回访安排，允许安心收工。收工收到的新咨询明确次日接洽，晚间回顾列出明天的安排。达标后继续提醒现有客户的服务，月末按实际记录确认已完成及尚未完成的首次回访、客户答复和理赔收尾。新开局问清考核与佣金不再扣评价。没有增加系统、事件或业绩目标。

保留v1自动及手动存档。新开局采用新的月份安排；旧档不降低属性、不改已认识客户的考虑日期、不重算历史收入，也不重播完成的剧情。换设备前可在生活账导出JSON，到新设备导入。

手机正文独立滚动，底部操作保持可达；保留双指缩放限制、网页和手机桌面图标。

## 验证

Node.js 20及以上运行 `node --test qa/*.test.mjs`。75项测试涵盖新手提示、实际收益预告、服务结局对照、新节奏、两种身份的20条正常月份路线、旧档恢复与续玩、历史规则对照、收工剧情队列和移动输入。qa/legacy-engine.mjs仅为历史规则回归入口，新开局测试直接使用正式引擎。

人物、公司及产品规则均为虚构。游戏静态运行，不依赖实时大模型。
