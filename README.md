# 明天一定开单

一个关于保险销售、业绩、人情和生活的 30 天叙事经营游戏。

**直接试玩：https://lynch715.github.io/mingtian-kaidan/**

无需登录，无后端服务。适合桌面与手机浏览器。

- 2 种开局身份、8 位主要人物、56 段剧情、6 种月末结局。
- 外呼、社区获客、面谈、成交、回访、转介绍与撤单。
- 亲友关系、自购、生活现金、房租与佣金结算。
- 吴师傅、陈静、陆先生、唐女士的专属事件。
- 一条分阶段理赔故事，包含材料核对、补件与审核结果。
- 亲友名单、业绩承诺、同事互助的跨天后果。
- 自动存档、手动备份及 JSON 导入导出。

存档保存在当前浏览器。切换网址或设备不会自动同步；请先在「生活账」页导出，再到新页面导入。

本轮内容更新保持原有 v1 存档位置与格式，读取旧档时补齐新增记录，原有天数、现金、保单和历史选择继续保留。每天最多出现一段补充故事。

本仓库保存可直接发布的静态游戏文件。人物、公司、产品及考核规则均为虚构。
